# Security

Report a vulnerability in **this image's changes** (the Containerfile, the
build, a regression we introduced) through GitHub's private vulnerability
reporting on this repository: Security → Report a vulnerability.

Vulnerabilities in **Hermes Agent itself** go to Nous Research upstream.

Supported: the newest `vX.Y.Z-patched` tag. Older dated tags are not
rebuilt; pull the moving tag or the newest digest.
